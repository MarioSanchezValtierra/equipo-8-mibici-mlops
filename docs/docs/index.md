# Equipo 8 - MiBici MLOps documentation!

## Description

Proyecto MLOps para predecir los flujos de entrada y salida de las estaciones de MiBici con tres días de anticipación, identificar posibles desequilibrios y apoyar la planeación operativa de la redistribución de bicicletas.

## Commands

The Makefile contains the central entry points for common tasks related to this project.
